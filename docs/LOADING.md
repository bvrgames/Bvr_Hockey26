# Загрузка игры

Замер: `npm run load` (tools/load.mjs) — Chromium в мобильном окне 800×384, CPU ×4, сервер как Vercel
(brotli, ETag/304, Cache-Control из vercel.json). «Меню» — меню показано и скрипт игры отработал;
«матч» — от нажатия «Старт» до матча с моделями игроков. Медианы двух прогонов. telegram-web-app.js
в замер не входит (в Telegram это ещё один блокирующий запрос к telegram.org).

Что прибавилось 29–30.09: упрощённые модели (LOD) +133 КБ в base64 внутри index.html и отдельный
`shared/sim.js` (+21 КБ, ещё один блокирующий запрос) — около +7 % байт; на телефоне заметнее
из-за того, что всё шло одним файлом, который надо было скачать целиком до запуска скрипта.

Что сделано:
- модели и текстуры вынесены из index.html в `assets/dist/` (tools/pack-assets.mjs), имена с хешем —
  кеш навсегда (`vercel.json`), index.html перепроверяется при каждом открытии;
- модели в двоичном виде вместо base64 и в двух пакетах: `players-lo` (скелет, анимация, упрощённые модели
  со своим компактным набором вершин, 194 КБ по сети) нужен всем; `players-hi` (полные модели, ~600 КБ)
  качается только для высокого качества, до его прихода рисуются упрощённые;
- `players-lo` начинает качаться скриптом в `<head>` параллельно с разбором страницы; меню его не ждёт;
  если нажать «Старт» раньше — экран загрузки с процентами, матч начнётся сам;
- исходники моделей — `assets/src/` (insert_clip.py, replace_clip.py, bake-lod.mjs пишут туда),
  `npm run check` падает, если после правки не запустили `npm run assets`.


## Меню, шрифт, музыка (01.10.2026, docs/MENU_PLAN.md)

- Меню — разметка, CSS и код в `index.html`: +18 КБ в сжатом виде (88 → 106 КБ). Открытие меню, медиана 3 прогонов
  `tools/load.mjs` на 4G: 474 → 509 мс (повторно 310 → 329 мс); медленный 3G — 4,2 → 4,9 с.
- Шрифт `assets/dist/font-lat|font-cyr.<хеш>.woff2` (26 + 13 КБ) подключается после первой отрисовки меню
  (FontFace, `display: swap`): до этого — системный; кириллица качается только для русского.
- Музыка `assets/dist/music-<хеш>.m4a` (AAC 96 кбит/с, 1,4–2,6 МБ): один трек, потоково (Range), начинает качаться
  после моделей игроков — на 3G иначе время до матча выросло на 1,8 с. Исходники `assets/src/` в деплой не входят
  (`.vercelignore`).
- Под непрозрачным меню и экраном поворота площадка не рисуется (и автоподстройка качества не считает fps).
